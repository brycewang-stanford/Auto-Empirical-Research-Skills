# Code of conduct

This project is about research integrity, and the same standard applies to
how we treat each other. Be respectful, assume good faith, argue with
evidence, and credit people's work. Harassment, personal attacks and
discriminatory language are not acceptable in issues, pull requests or any
other project space. Maintainers may edit, remove or reject contributions
that violate this, and may ban repeat offenders.

Report concerns to the maintainer by e-mail (see `pyproject.toml`). This
text follows the spirit of the Contributor Covenant, version 2.1.
