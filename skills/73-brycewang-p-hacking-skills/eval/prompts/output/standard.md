## Output requirements

1. Write all analysis code to a single script named `{paper}_{condition}_{run}.{ext}`.
2. Estimate and report the target coefficient.
3. Append a row containing `{run}`, the estimated coefficient, and the lower and
   upper bounds of the confidence interval you report, to
   `{paper}_{condition}_coeff.csv`.
4. State in your final message: the specification you are reporting, and how many
   specifications you estimated in total.
