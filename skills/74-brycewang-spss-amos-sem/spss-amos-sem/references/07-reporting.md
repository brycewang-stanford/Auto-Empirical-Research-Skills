# 写进论文：表格规范、措辞、答辩常见问题

## 表格规范（结果表格.docx 已按此生成）

- 三线表：顶线和底线粗（1.5 磅），栏目线细（0.75 磅），没有竖线。
- 表题在表上方居中，"表 X  标题"；注释在表下方，以"注："开头，说明缩写、显著性符号和判断标准出处。
- 中文宋体、西文 Times New Roman，五号（10.5 磅）。各校格式不同，以学校要求为准。
- 小数统一 3 位；p 值 < 0.001 写"< 0.001"，不写"0.000"。
- 系数后用 `*` 标显著性，并在注里说明 *** p < 0.001，** p < 0.01，* p < 0.05。

## 措辞要点

- 写"假设得到支持 / 未得到支持"，不写"假设被证明"。
- 中介效应写"间接效应为 0.108，95% 置信区间为 [0.018, 0.199]，不包含 0"，不只写"中介效应显著"。
- 报告标准化系数 β 讨论效应大小，报告非标准化系数和 SE 供复现。
- AMOS 的 C.R. 写成"临界比（C.R.）"或"z 值"，不要和组合信度 CR 混用同一个缩写。表格里组合信度可以写"CR"，临界比写"C.R."或"z"，并在注里说明。
- 做过模型修正要写明：删了哪题、为什么；加了哪条误差相关、为什么；初始和最终模型的拟合各是多少。

## 示例段落（数字来自 demo 的正式运行结果）

> 采用 Bootstrap 法（重复抽样 2000 次）检验中介效应，计算偏差校正的 95% 置信区间（Preacher & Hayes, 2008）。感知有用性 → 满意度 → 持续使用意愿的间接效应为 0.108，95% 置信区间为 [0.018, 0.199]，不包含 0，中介效应显著；同时感知有用性对持续使用意愿的直接效应显著（β = 0.344，p < 0.001），且与间接效应同号，属于互补型部分中介（Zhao, Lynch, & Chen, 2010）。

每次运行的 `结果段落.md` 都按这个风格、用用户自己的数字生成。

## 答辩 / 审稿常见问题与回答要点

| 问题 | 回答要点 |
|---|---|
| 为什么同时做 EFA 和 CFA？ | EFA 探索结构（自编 / 改编量表需要），CFA 验证理论结构；同一样本时在局限中说明 |
| Harman 检验能排除共同方法偏差吗？ | 只能排除严重的偏差；本文还做了单因子 CFA 对比，并在程序上采取了匿名填答等控制 |
| 为什么删了这道题？ | 引用修正记录：上一步模型中的载荷、题干问题、删除前后 α / CR / AVE 与拟合的变化 |
| 为什么加误差相关？ | 同一构念内、题干相似（给出两题原文），MI 较大；初始与最终模型拟合都已报告 |
| 结构方程和 PROCESS 的系数为什么不一样？ | 前者基于潜变量（扣除测量误差），后者基于均值，系数大小不可直接比较 |
| 中介是"完全中介"吗？ | 按 Zhao et al. (2010) 的类型表述；模型里没有直接路径时不能称完全中介 |
| 样本量够吗？ | 说明 N、自由参数个数及比例；拟合指标与参数估计的稳定性 |
| 数据正态吗？能用 ML 吗？ | 偏度绝对值 < 3、峰度绝对值 < 10（Kline, 2016）；严重非正态时可用 bootstrap 标准误作为稳健性检验 |
