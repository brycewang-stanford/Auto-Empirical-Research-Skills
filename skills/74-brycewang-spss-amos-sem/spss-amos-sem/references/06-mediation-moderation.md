# 中介与调节：SEM 还是 PROCESS？

## 两条路线

| | SEM（AMOS / lavaan，设定卡 `indirect`） | PROCESS（SPSS 宏，设定卡 `process`） |
|---|---|---|
| 变量 | 潜变量，扣除了测量误差 | 构念均值（观测变量） |
| 估计 | 最大似然，全模型同时估计 | 逐个方程 OLS |
| 间接效应检验 | 偏差校正 bootstrap（AMOS 的 Bias-corrected） | 百分位 bootstrap（PROCESS v4 默认） |
| 适合 | 多条中介路径、链式中介、整体模型 | 调节、有调节的中介（潜变量交互在 AMOS 里很难做） |
| 报告 | 具体间接效应（自定义估计量）、效应分解 | 条件间接效应、有调节的中介指数、简单斜率、J-N |

常见组合：**主模型和中介用 SEM，调节和有调节的中介用 PROCESS**。论文里要说明两部分分别基于潜变量和均值，所以系数大小不同。

## SEM 中介

- 每条中介路径写成一行，例如 `H8: PU -> SAT -> CI`；支持链式中介 `X -> M1 -> M2 -> Y`。
- 引擎自动给出：
  - 具体间接效应（非标准化点估计、Boot SE、BC 95% CI、百分位 CI、标准化点估计）；
  - 每对 X→Y 的效应分解：直接效应、**全部**间接路径之和（= AMOS 的 Indirect Effects）、总效应。
- 中介类型按 Zhao, Lynch, & Chen (2010) 判断：

| 间接效应 | 直接效应 | 类型 |
|---|---|---|
| 显著 | 显著且与间接效应同号 | 互补型部分中介 |
| 显著 | 显著且与间接效应异号 | 竞争型部分中介 |
| 显著 | 不显著 | 仅间接效应（完全中介） |
| 显著 | 模型中没有直接路径 | 仅间接效应（模型未设直接路径），不能称为"完全中介" |
| 不显著 | 显著 | 仅直接效应（无中介） |
| 不显著 | 不显著 | 无效应 |

直接效应显著与否用与假设检验表相同的 z 检验；间接效应用 bootstrap 置信区间。

国内文献常引用逐步检验（Baron & Kenny）和温忠麟、叶宝娟 (2014) 梳理的检验流程，后者把 bootstrap 列为检验间接效应 ab 的推荐方法之一。本 skill 统一用 bootstrap 置信区间判断间接效应，也不要求"X→Y 总效应显著"才能检验中介（Zhao et al., 2010）。

## PROCESS 模型（引擎支持的）

| 模型 | 结构 | 关键结果 |
|---|---|---|
| 1 | 简单调节：W 调节 X→Y | 交互项系数、ΔR²、条件效应（W 的第 16/50/84 百分位）、Johnson-Neyman 转折点 |
| 4 | 中介（可并行多个 M） | a、b、c′，各条间接效应及总间接效应（多于一个 M 时） |
| 6 | 链式中介（2–4 个 M，按顺序） | 所有链上的间接效应（2 个 M 时 3 条：X→M1→Y、X→M2→Y、X→M1→M2→Y） |
| 7 | 第一阶段有调节的中介：W 调节 X→M | 条件间接效应、有调节的中介指数 = a₃ × b |
| 8 | 同 7，且 W 也调节 X→Y | 条件间接效应、条件直接效应、指数 = a₃ × b |
| 14 | 第二阶段有调节的中介：W 调节 M→Y | 条件间接效应、指数 = a × b₃ |

- `center: true`（默认）= PROCESS 的 `center=1`：交互项由均值中心化后的变量构成。条件值以原始量表单位报告。
- 二分类调节变量（如性别 1/2）自动取两个取值作为条件值。
- **有调节的中介是否成立看"有调节的中介指数"的置信区间**（Hayes, 2022），不是看各条件间接效应是否都显著。各水平都显著但指数不显著，说明调节作用不成立。
- 引擎与 PROCESS 的点估计完全一致（同为 OLS）；bootstrap 区间因随机数不同在第三位小数上可能有差别。

## 潜变量交互（不在本 skill 范围）

AMOS 里做潜变量调节（乘积指标法、LMS）门槛高、结果不稳定，毕业论文一般用 PROCESS 处理调节。如果用户坚持要潜变量交互，告诉用户这超出本 skill 范围，可以用 Mplus（XWITH）或 R 的 `semTools::indProd` 自行处理。
