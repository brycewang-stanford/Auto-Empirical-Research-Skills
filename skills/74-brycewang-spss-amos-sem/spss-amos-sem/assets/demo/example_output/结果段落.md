## 样本概况

本研究共回收问卷 430 份，剔除规律作答（所有题目选同一选项）的问卷 8 份，剔除存在缺失值的问卷 17 份，最终得到有效问卷 405 份，有效回收率为 94.19%。

## 共同方法偏差检验

采用 Harman 单因素检验（Podsakoff et al., 2003；周浩、龙立荣, 2004），对全部 17 个题项做未旋转的探索性因子分析，共提取出 5 个特征值大于 1 的因子，第一个因子的方差解释率为 32.06%，低于 40% 的临界标准，说明本研究不存在严重的共同方法偏差。
进一步将所有题项设定为负荷在同一个因子上做验证性因子分析，单因子模型的拟合（χ²/df = 14.036，CFI = 0.490，RMSEA = 0.180）明显差于 5 因子测量模型（Δχ² = 1513.62，Δdf = 11，p < 0.001），再次说明共同方法偏差不严重。

## 信度分析

各构念的 Cronbach's α 系数介于 0.800 ~ 0.875 之间，均大于 0.7，说明量表具有良好的内部一致性；各题项的 CITC 均大于 0.5，删除任一题项都不会使所在构念的 α 明显提高。

## 效度分析

### 探索性因子分析

KMO 值为 0.851，Bartlett 球形检验的近似卡方为 3128.57（df = 136，p < 0.001），说明数据适合做因子分析。采用主成分分析法、最大方差旋转，按理论维度提取 5 个因子，累计方差解释率为 72.15%，超过 60% 的经验标准。
各题项均在所属因子上有较高载荷（> 0.5），且没有明显的交叉载荷，因子结构与理论设想一致。

### 收敛效度

使用 AMOS 进行验证性因子分析。测量模型拟合良好与否见下文；各题项的标准化因子载荷介于 0.658 ~ 0.872 之间，均大于 0.5 且在 0.001 水平上显著，组合信度（CR）介于 0.801 ~ 0.876 之间，平均方差抽取量（AVE）介于 0.528 ~ 0.702 之间，均达到 CR > 0.7、AVE > 0.5 的标准（Fornell & Larcker, 1981），说明量表具有良好的收敛效度。

### 区分效度

各构念 AVE 的平方根均大于其与其他构念的相关系数，满足 Fornell-Larcker 准则；HTMT 值最大为 0.518，低于 0.85 的严格标准（Henseler et al., 2015），说明各构念之间具有良好的区分效度。

## 模型拟合

测量模型的拟合指标为：χ²/df = 1.451，CFI = 0.984，TLI = 0.980，IFI = 0.984，RMSEA = 0.033，SRMR = 0.036。各项指标均达到可接受水平（Hu & Bentler, 1999），测量模型拟合良好。
需要说明的是，测量模型在初始设定基础上做了 2 处修正（删除题项 TR4；增加误差相关 SAT1 ↔ SAT2），修正理由与每一步的拟合变化见模型修正记录。

## 假设检验

结构模型的拟合指标为：χ²/df = 1.436，CFI = 0.984，TLI = 0.981，RMSEA = 0.033，SRMR = 0.037。路径分析结果显示：
- H1：感知易用性对感知有用性的标准化路径系数为 0.451（z = 7.085，p < 0.001），正向影响显著，假设得到支持。
- H2：感知有用性对满意度的标准化路径系数为 0.487（z = 7.306，p < 0.001），正向影响显著，假设得到支持。
- H3：感知易用性对满意度的标准化路径系数为 0.153（z = 2.309，p = 0.021），正向影响显著，假设得到支持。
- H4：信任对满意度的标准化路径系数为 0.230（z = 3.861，p < 0.001），正向影响显著，假设得到支持。
- H5：满意度对持续使用意愿的标准化路径系数为 0.204（z = 2.516，p = 0.012），正向影响显著，假设得到支持。
- H6：感知有用性对持续使用意愿的标准化路径系数为 0.344（z = 4.710，p < 0.001），正向影响显著，假设得到支持。
- H7：信任对持续使用意愿的标准化路径系数为 0.044（z = 0.741，p = 0.459），未达到显著水平，假设不成立。

综上，H1、H2、H3、H4、H5、H6得到支持，H7未得到支持。模型对感知有用性、满意度、持续使用意愿的解释力（R²）分别为 0.203、0.440、0.256。

## 中介效应检验

采用 Bootstrap 法（重复抽样 2000 次）检验中介效应，计算偏差校正的 95% 置信区间（Preacher & Hayes, 2008）。结果如下：
- H8：感知有用性 → 满意度 → 持续使用意愿 的间接效应为 0.108，95% 置信区间为 [0.018, 0.199]，不包含 0，中介效应显著，属于互补型部分中介。
- H9：感知易用性 → 感知有用性 → 满意度 的间接效应为 0.255，95% 置信区间为 [0.166, 0.371]，不包含 0，中介效应显著，属于互补型部分中介。
- H10：感知易用性 → 感知有用性 → 满意度 → 持续使用意愿 的间接效应为 0.057，95% 置信区间为 [0.011, 0.116]，不包含 0，中介效应显著，属于仅间接效应（模型未设直接路径）。

## 多群组分析

以性别为分组变量进行测量不变性检验。弱等价（载荷相等）：ΔCFI = 0.000，ΔRMSEA = -0.001，成立。强等价（载荷 + 截距相等）：ΔCFI = 0.002，ΔRMSEA = -0.003，成立。在此基础上比较各结构路径的组间差异，所有路径在两组间均无显著差异。
