# A02 公共数据源发现

> 来源：《社会科学研究Agent Skills手册·通用版2026》第59页（044 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

在数据档案、政府、国际组织和研究项目中找可复用数据并核对官方入口。

## 必须输入（手册原文）

数据需求规格、候选来源、许可/账户条件、时间地理范围、需要的变量与键。

## 标准流程（手册原文）

1. 从研究问题倒推数据规格。
2. 优先寻找官方/权威入口。
3. 记录许可、版本和访问条件；本技能特别检查二手博客或网盘成为唯一来源这一失败模式。
4. 保存原始快照/哈希与采集脚本。
5. 任何自动抽取都做样本级人工核验。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于公共数据源发现，不得只给一段自然语言总结。

## 人工关口（手册原文）

可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。

## 最常见的翻车点（手册原文）

二手博客或网盘成为唯一来源。

## 核验依据（手册原文）

S08 · S29 · S30 · S31 · S32

## 推荐实现（手册原文）

政府/项目官网、数据档案、API、网页快照与哈希工具；优先官方来源，不绕过许可。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：二手博客或网盘成为唯一来源。
- [ ] 已满足人工关口：可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
