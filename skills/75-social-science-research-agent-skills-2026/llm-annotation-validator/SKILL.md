# X04 LLM 标注验证

> 来源：《社会科学研究Agent Skills手册·通用版2026》第122页（102 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

|---|---|---|

## 何时调用（触发条件，手册原文）

在代表性人工 gold set 上报告 accuracy/F1、分组误差、提示词敏感性和模型版本。

## 必须输入（手册原文）

语料/网络/空间/平台数据、gold set、代码本、模型与提示词版本、验证样本。

## 标准流程（手册原文）

1. 定义可观察总体与数据生成机制。
2. 建立人工 gold set 与基线。
3. 固定模型/提示词/预处理版本；本技能特别检查引用别人论文的高准确率替代自己数据上的验证这一失败模式。
4. 报告整体与分组错误。
5. 只有通过本地验证的自动化标签才能进入正式分析。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于LLM 标注验证，不得只给一段自然语言总结。

## 人工关口（手册原文）

研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。

## 最常见的翻车点（手册原文）

引用别人论文的高准确率替代自己数据上的验证。

## 核验依据（手册原文）

S34 · S35 · S36 · S38

## 推荐实现（手册原文）

Python/R + NLP/网络/空间库 + LLM API；必须有 gold set、版本锁定与偏误评估。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：引用别人论文的高准确率替代自己数据上的验证。
- [ ] 已满足人工关口：研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
