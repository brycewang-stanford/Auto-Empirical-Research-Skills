# W03 主张-引文-事实审计

> 来源：《社会科学研究Agent Skills手册·通用版2026》第147页（125 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

逐句检查每个事实/数字/文献主张是否由对应原文支持，避免二手转述漂移。

## 必须输入（手册原文）

最新稿件、表图、参考文献库、目标期刊政策、附录与复现包。

## 标准流程（手册原文）

1. 先固定论证主线与证据边界。
2. 表图、正文、附录从同一结果对象生成。
3. 逐句核验数字和引文；本技能特别检查引用真实存在，但不支持正文那句话这一失败模式。
4. 核对目标期刊最新政策。
5. 最后做红队审稿与投稿包一致性检查。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于主张-引文-事实审计，不得只给一段自然语言总结。

## 人工关口（手册原文）

可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。

## 最常见的翻车点（手册原文）

引用真实存在，但不支持正文那句话。

## 核验依据（手册原文）

S27 · S31 · S32 · S33

## 推荐实现（手册原文）

Zotero/文献库 + 目标期刊官网 + 自动表图流水线；保密审稿材料只进合规环境。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：引用真实存在，但不支持正文那句话。
- [ ] 已满足人工关口：可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
