# E09 数据合并审计

> 来源：《社会科学研究Agent Skills手册·通用版2026》第77页（061 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

在 merge 前验证键唯一性，merge 后报告 1:1/m:1 状态、未匹配原因和样本流失。

## 必须输入（手册原文）

原始数据只读副本、代码本、现有清洗/合并脚本、唯一键和输出目标。

## 标准流程（手册原文）

1. 原始数据只读归档。
2. 先做画像和唯一键检查。
3. 脚本化清洗/合并并输出日志；本技能特别检查为了提高匹配率静默删除未匹配样本这一失败模式。
4. 维护变量字典与数据血缘。
5. 冻结分析数据并版本化后续变更。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于数据合并审计，不得只给一段自然语言总结。

## 人工关口（手册原文）

可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。

## 最常见的翻车点（手册原文）

为了提高匹配率静默删除未匹配样本。

## 核验依据（手册原文）

S28 · S29 · S30 · S31

## 推荐实现（手册原文）

R/Python/Stata/SQL + Git/DVC 或等价版本工具 + 数据字典；所有中间步骤脚本化。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：为了提高匹配率静默删除未匹配样本。
- [ ] 已满足人工关口：可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
