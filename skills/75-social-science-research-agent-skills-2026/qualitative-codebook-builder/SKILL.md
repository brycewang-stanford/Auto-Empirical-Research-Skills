# K06 编码本构建

> 来源：《社会科学研究Agent Skills手册·通用版2026》第111页（092 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

从理论与开放编码形成代码名、定义、纳入/排除、正反例和层级关系。

## 必须输入（手册原文）

研究问题、抽样方案、原始音视频/转录、代码本、研究者备忘录和伦理要求。

## 标准流程（手册原文）

1. 保留原始语境与反身性记录。
2. 用明确代码本/抽样策略管理资料。
3. Agent 负责整理、候选编码和检索；本技能特别检查代码标签互相重叠且定义随访谈变化这一失败模式。
4. 人负责主题、解释与反例判断。
5. 把分歧、负案例与版本写入审计轨迹。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于编码本构建，不得只给一段自然语言总结。

## 人工关口（手册原文）

研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。

## 最常见的翻车点（手册原文）

代码标签互相重叠且定义随访谈变化。

## 核验依据（手册原文）

S24 · S25 · S26 · S38

## 推荐实现（手册原文）

NVivo/MAXQDA/Atlas.ti 或结构化表格 + 转录工具 + LLM；原始材料隐私优先。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：代码标签互相重叠且定义随访谈变化。
- [ ] 已满足人工关口：研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
