# L06 DOI 与元数据解析

> 来源：《社会科学研究Agent Skills手册·通用版2026》第39页（026 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

用 Crossref/DataCite 等核对标题、作者、期刊、年份、DOI 与发表状态。

## 必须输入（手册原文）

研究问题、种子文献、概念同义词、时间/语言/学科边界、检索截止日。

## 标准流程（手册原文）

1. 建立概念组和同义词。
2. 至少覆盖结构化元数据检索与引文网络。
3. 为每条记录解析 DOI/作者/版本；本技能特别检查直接相信 LLM 生成的参考文献字符串这一失败模式。
4. 去重并核查更正/撤稿。
5. 保存可复现检索日志和截止日期。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于DOI 与元数据解析，不得只给一段自然语言总结。

## 人工关口（手册原文）

可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。

## 最常见的翻车点（手册原文）

直接相信 LLM 生成的参考文献字符串。

## 核验依据（手册原文）

S06 · S07 · S08 · S09 · S10 · S11 · S12 · S13 · S14 · S15

## 推荐实现（手册原文）

Crossref、OpenAlex、Semantic Scholar、DataCite、Unpaywall、ORCID、Zotero；引文网络可辅以 ResearchRabbit/Connected Papers。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：直接相信 LLM 生成的参考文献字符串。
- [ ] 已满足人工关口：可让 Agent 批量执行，但至少进行规则级检查、随机抽样复核和异常项人工复核；自动化结果不得绕过最终质量门。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
