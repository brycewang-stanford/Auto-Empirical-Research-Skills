# V07 FAIR/TIER 复现包审计

> 来源：《社会科学研究Agent Skills手册·通用版2026》第138页（117 / 128）。以下「手册原文」各节逐字摘自该页；「最终检查」一节按手册第3页「如何使用这本手册」、第9页「十条研究Agent底线」第01条与本页内容整理。

## 何时调用（触发条件，手册原文）

按 FAIR、TIER 和期刊政策检查数据、脚本、元数据、引用与可移植性。

## 必须输入（手册原文）

项目目录、原始数据/代码、环境文件、README、输出、Agent 执行日志和当前 skill。

## 标准流程（手册原文）

1. 所有计算都脚本化。
2. 锁定环境与随机性。
3. 主结果做独立实现/冷启动复现；本技能特别检查只上传 analysis.do，不含清洗和数据来源这一失败模式。
4. 记录 AI 提示词、模型和人工更改。
5. 把稳定流程封成小 skill 并持续评估。

## 输出契约（手册原文）

输出必须包含：①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。对于FAIR/TIER 复现包审计，不得只给一段自然语言总结。

## 人工关口（手册原文）

研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。

## 最常见的翻车点（手册原文）

只上传 analysis.do，不含清洗和数据来源。

## 核验依据（手册原文）

S01 · S02 · S03 · S04 · S05 · S27 · S28 · S31 · S37

## 推荐实现（手册原文）

Git + 环境锁文件/容器 + README + OSF/Dataverse/Zenodo 等仓储 + Agent Skills 目录。

## 最终检查

交付前逐项确认，任何一项不满足都不得交付：

- [ ] 输出包含①结论/建议；②采用的规则或口径；③逐项证据或数据位置；④无法确认项；⑤下一步人工决策。不是只给一段自然语言总结。
- [ ] 已专门检查并排除本技能最常见的翻车点：只上传 analysis.do，不含清洗和数据来源。
- [ ] 已满足人工关口：研究者必须最终批准关键判断，并能回答为什么这个规则适用于当前问题。Agent 可做机械检索、整理、计算和一致性检查，但不得把未验证推断写成事实。
- [ ] 已留审计轨迹：记录来源、检索截止、模型版本、提示词、代码、输入数据版本与人工修改，确保同一研究能复盘。
- [ ] 查不到的文献、DOI、页码、数据、引语和政策事实明确写「未核实」，不生成或补齐。
